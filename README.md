# Anshu's Website | AI Video Editor & Motion Designer

A world-class, premium dark-themed cinematic portfolio website for **Anshu Kushwaha** (AI Video Editor & Motion Designer based in Mumbai, Vasai).

## ⚡ Highlights & Features

- **Cinematic Dark Aesthetic**: Obsidian/charcoal backdrop with electric neon cyan and hyper-violet accents.
- **Interactive Lightning Cursor**: High-voltage fractal lightning arcing trail, spark discharge, and drag overdrive.
- **Selected Works Showcase**: Categorized video portfolio with video player modal supporting YouTube embeds and shorts.
- **Before-and-After VFX Comparison**: Interactive draggable split comparison between RAW camera log footage and final graded VFX.
- **Instagram Reels & YouTube Shorts Gallery**: Direct responsive video cards with view counts and channel links.
- **Tools Behind The Vision**: Interactive skills cards with animated proficiency indicators (Premiere Pro, After Effects, Photoshop, Illustrator, Blender, Canva, Figma).
- **AI Suite Showcase**: ChatGPT & Gemini, Higgsfield AI, Magnific AI, and Adobe Firefly integration.
- **Contact Channels**: Interactive project inquiry form, copy-to-clipboard email, direct WhatsApp button, and phone contact.
- **Centralized Data File**: Easy customization via `src/data/portfolio.ts`.

## 🛠️ Tech Stack

- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **HTML5 Canvas** (VFX Lightning & Particle System)

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

## 📦 Building for Production

```bash
npm run build
```

The production output will be generated in `dist/`.
